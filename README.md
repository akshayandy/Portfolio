# Akshay Kanth Bendhela — Portfolio

This is my personal portfolio: a place to share my work and experience in conversational AI, cloud platforms, and software development.

## The story behind the rebuild

My old portfolio no longer reflected the work I do today, so I decided it was time for a refresh. I built the updated site using GitHub Copilot in VS Code for the web, working from my iPad.

Instead of starting with a fixed design, I treated the process as a conversation. I described what I wanted to improve, reviewed the page in the browser, and used screenshots to point out details that needed another pass—from layout and alignment to the skills list. Copilot helped turn that feedback into changes, while I guided the direction and decided what felt right.

Working this way made it possible to shape a complete portfolio from a tablet: updating the content, refining the responsive design, and removing assets left behind by the old site. It was a practical reminder that you can build thoughtfully by focusing on the result, giving clear feedback, and iterating—even without a traditional desktop setup.
